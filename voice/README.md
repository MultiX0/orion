# Voice

Orion speaks with **Orion Voice** on Fish Audio, voice id `9a68c1d739134940a4297c996c5ca6a1`. Everything about the voice, the languages, the emotion tags and the system prompt is in [docs/VOICE.md](../docs/VOICE.md).

This folder is the record of how the voice was chosen before Orion Voice existed:

- `VOICE_v1.md` and `auditions/`: the first voice, a Levantine library voice, with its audition and measurements.
- `VOICE.md` and `auditions_v2/`: the second, a Modern Standard Arabic library voice, with its audition, tiebreak and emotion tag tests.
- `reference/`: where recordings of your own voice would go if you wanted to clone one.
