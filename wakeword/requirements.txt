# Pinned to what actually trained the shipped model, on python 3.11.16 in

#
#   uv venv --python 3.11 ~/orion_ww/.venv
#   uv pip install --python ~/orion_ww/.venv/bin/python -r requirements.txt
#   uv pip install --python ~/orion_ww/.venv/bin/python --no-deps -e work/mww
#
# Notes that cost time to find:
# - datasets must stay under 4. Version 4 decodes audio through torchcodec,
#   which has no usable wheel here, and microwakeword.audio.clips imports it.
# - tensorflow is pinned as the plain CPU wheel. The shipped model was trained
#   with the GPU set on top of it, installed afterwards with
#     uv pip install --no-cache "tensorflow[and-cuda]==2.20.0"
#   which adds 12 nvidia wheels (cuda 12.9, cudnn 9.26) and 4.2 GB on disk.
#   Only worth it when the disk has the room; see the journal.
# - piper-tts is the ONNX runtime, not the torch sample generator.
